   312→   312→
   313→   313→Нужно защитить все места, где в HTML-атрибуты попадают данные из состояния.
   314→   314→
   315→   315→Файл:

   321→   321→Проблемные места:

   324→   324→- `data-card-id="card-node-${card.id}"`
   325→   325→- `data-theme="${cardTheme}"`
   326→   326→- `data-format="${settings.format}"`
   327→   327→

   329→   329→

   331→   331→2. Использовать `escapeHtml` или отдельный `escapeAttr`.

   333→   333→

   335→   335→
   336→   336→```ts
   337→   337→function sanitizeCardId(id: unknown): string {
   338→   338→  if (typeof id !== "string") return crypto.randomUUID();
   339→   339→  if (!/^[a-zA-Z0-9_-]{1,64}$/.test(id)) return crypto.randomUUID();
   340→   340→  return id;
   341→   341→}
   342→   342→```
